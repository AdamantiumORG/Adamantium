# Changelog

Adamantium follows [Semantic Versioning](docs/VERSIONING.md). Tagged releases
receive generated release notes grouped into breaking changes, features, fixes,
performance work, and tooling changes.

## Unreleased

Development changes are published through the moving `dev` and `nightly`
channels. The stable release workflow generates the final changelog from Git
history when a `vMAJOR.MINOR.PATCH` tag is pushed.
